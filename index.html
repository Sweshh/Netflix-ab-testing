The Netflix case, in plain English

When you open Netflix, the thumbnail image you see for a show isn't fixed — it's often chosen specifically for you, from a pool of different artwork options for that same title. Netflix has found that the image alone can meaningfully change whether someone clicks on a show, independent of the show itself.

The business problem is simple to state and hard to answer with intuition alone: if you change only the artwork, does more people clicking on it actually mean more people watch and enjoy the content, or are you just chasing clicks? Netflix's answer has been to stop guessing and instead run controlled experiments — showing different artwork to different, randomly chosen groups of members, then measuring what happens.

That's the idea behind A/B testing, and it's a core part of how machine learning and experimentation work together in industry: a model or a design choice proposes a change, and an experiment tells you, with real evidence, whether that change actually moves the number you care about. This project recreates a simplified version of that process from scratch.

What I built

I simulated a Netflix-style experiment in Python across three steps. Each step answers one question in the experimentation process.

1. Simulate the experiment

1,000 users are randomly split between two artwork versions, Artwork A and Artwork B. Artwork A has a 24% true click probability and Artwork B has a 30% true click probability (numbers I set deliberately, to test whether the experiment could correctly detect a known difference). Each user's click is then simulated based on the version they saw, and the results are stored in a table with a user ID, their assigned version, and whether they clicked.

2. Measure the results

For each version, I calculated the total number of users, the total number of clicks, and the click-through rate — the percentage of people who clicked. I then built a bar chart so the two rates could be compared at a glance.

3. Test whether the difference is real

A gap between two percentages can happen purely by chance, especially with a limited sample of users. I ran a statistical test — a two-proportion z-test — to check whether the gap between Artwork A and Artwork B was large enough to be considered a genuine effect, rather than random noise.

The code

All three steps below run in a single Google Colab notebook. It generates the simulated data, summarizes the results, produces the chart, and runs the significance test.

netflix_artwork_ab_test.py 
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from statsmodels.stats.proportion import proportions_ztest

# Set a random seed for reproducibility
np.random.seed(42)

# Number of users in the experiment
n_users = 1000

# Click probabilities for each artwork version
p_click_A = 0.24
p_click_B = 0.30

# Step 1: Create user IDs
user_ids = np.arange(1, n_users + 1)

# Step 2: Randomly assign each user to Artwork A or Artwork B (50/50 split)
artwork_assignment = np.random.choice(['A', 'B'], size=n_users, p=[0.5, 0.5])

# Step 3: Simulate whether each user clicks, based on their assigned artwork's probability
clicks = np.where(
    artwork_assignment == 'A',
    np.random.binomial(1, p_click_A, size=n_users),
    np.random.binomial(1, p_click_B, size=n_users)
)

# Step 4: Combine everything into a DataFrame
df = pd.DataFrame({
    'user_id': user_ids,
    'artwork_version': artwork_assignment,
    'clicked': clicks
})

# Step 5: Calculate total users, total clicks, and click-through rate per group
summary = df.groupby('artwork_version')['clicked'].agg(
    total_users='count',
    total_clicks='sum',
    click_through_rate='mean'
).reset_index()

print(summary)

# Step 6: Bar chart comparing click-through rates
plt.figure(figsize=(6, 5))
bars = plt.bar(
    summary['artwork_version'],
    summary['click_through_rate'],
    color=['#E50914', '#221F1F'],
    width=0.5
)

for bar, rate in zip(bars, summary['click_through_rate']):
    plt.text(
        bar.get_x() + bar.get_width() / 2,
        bar.get_height() + 0.005,
        f'{rate:.1%}',
        ha='center',
        fontsize=12,
        fontweight='bold'
    )

plt.title('Click-Through Rate by Artwork Version', fontsize=14, fontweight='bold')
plt.xlabel('Artwork Version')
plt.ylabel('Click-Through Rate')
plt.ylim(0, max(summary['click_through_rate']) + 0.05)
plt.tight_layout()
plt.show()

# Step 7: Statistical test - two-proportion z-test
clicks_A = summary.loc[summary['artwork_version'] == 'A', 'total_clicks'].values[0]
clicks_B = summary.loc[summary['artwork_version'] == 'B', 'total_clicks'].values[0]
n_A = summary.loc[summary['artwork_version'] == 'A', 'total_users'].values[0]
n_B = summary.loc[summary['artwork_version'] == 'B', 'total_users'].values[0]

count = np.array([clicks_A, clicks_B])
nobs = np.array([n_A, n_B])

z_stat, p_value = proportions_ztest(count, nobs)

print(f"\nArtwork A: {clicks_A} clicks out of {n_A} users ({clicks_A/n_A:.2%})")
print(f"Artwork B: {clicks_B} clicks out of {n_B} users ({clicks_B/n_B:.2%})")
print(f"\nZ-statistic: {z_stat:.4f}")
print(f"P-value: {p_value:.4f}")

alpha = 0.05
if p_value < alpha:
    print(f"\nResult: p-value ({p_value:.4f}) < {alpha} → The difference is statistically significant.")
    print("This suggests the difference in click-through rates is unlikely due to random chance.")
else:
    print(f"\nResult: p-value ({p_value:.4f}) >= {alpha} → The difference is NOT statistically significant.")
    print("This suggests we cannot rule out that the difference happened by random chance.")

Artwork B outperformed Artwork A by about 6.6 percentage points, roughly a 26% relative improvement in click-through rate. On its own, that gap could be a real effect, or it could be the kind of variation you'd expect just from randomly splitting 1,000 people into two groups. To tell those apart, the difference has to be tested statistically — which is exactly what Netflix does before treating any A/B test result as a real finding.

STATISTICAL TEST

A two-proportion z-test compares two percentages and asks: if there were truly no difference between Artwork A and Artwork B, how likely is it that random chance alone would produce a gap this large? The test returned a p-value of 0.022. Since that is below the standard 0.05 threshold used across the industry, the result is treated as statistically significant — the evidence favors a real difference, not random noise.

What Netflix should do

In a real version of this test, run across millions of members rather than 1,000, Netflix would have far more statistical power to detect even smaller differences with confidence. Based on this result, the recommended action is straightforward:

Roll out Artwork B

Artwork B produced a meaningfully higher click-through rate than Artwork A, and the difference is unlikely to be due to chance. Netflix should adopt Artwork B as the default image for this title and continue monitoring downstream engagement — such as watch time and completion rate — to confirm that the extra clicks translate into more people actually watching and enjoying the show, not just more clicks.

This is the same logic that underlies Netflix's real artwork personalization system: a few percentage points of click-through lift, applied across a massive member base, adds up to a substantial amount of additional viewing. It's also why experimentation, not intuition, drives decisions like this — a design that "feels" better isn't rolled out until the data backs it up.
